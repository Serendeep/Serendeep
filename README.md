### Projects

- [latch](https://github.com/Serendeep/latch) lets a coding agent run a command with a secret. You approve the exact command once in a popup, and the value never reaches the chat or a `.env` file. Rust and Tauri.
- [fv-tv-repro](https://github.com/Serendeep/fv-tv-repro) holds the code, task data and outputs behind the paper. Every table and figure regenerates from committed results.
- [cratemind](https://github.com/Serendeep/cratemind) turns a Spotify playlist into a DJ crate sorted by BPM, Camelot key and genre, with the audio analysed locally.
- [Marginalia](https://github.com/Serendeep/marginalia) keeps handwritten notes pinned to the lecture PDF page they belong to. An Android tablet app in Kotlin and Compose.
- [brew-rs](https://github.com/brew-rs/homebrew-rust) is Homebrew rewritten in Rust, with a SAT solver for dependency resolution.

I've also landed a few fixes in [T3 Code](https://github.com/pingdotgg/t3code/pulls?q=is%3Apr+is%3Amerged+author%3ASerendeep).
